# A type script language based code editor for web

## with beautiful themes, Framework agonistic

## with demo run from system

1. build the the built code from source code
2. with a local web server you setup with python (on your machine web server code not provided in this repository ) you can host the demo html and check the demo


---

## Features

* **Framework Agnostic:** Seamlessly integrates into any web application .
* **Vibrant Themes:** Built-in theme support including custom high-contrast and fruity plum palettes.
* **Modern Design System:** Completely structured using `rem` units, sleek glassmorphism button styles, and smooth hover interactions.
* **Code Intelligence & Diagnostics:** Inline error highlighting, customizable gutter line markers, and floating hover tooltips.
* **Modular Architecture:** Extensible barrel-module design splitting syntax tokenization, diffing algorithms, UI components, and state management.
